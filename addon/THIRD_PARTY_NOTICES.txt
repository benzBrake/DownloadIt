DownloadIt
==========

DownloadIt is an unofficial modern Firefox port based on the original
FlashGot extension, which is Copyright (C) Giorgio Maone and distributed
under GPL-2.0-or-later.

FlashGot.exe
===============

FlashGot.exe is based on Grabby-FlashGot by pouriap and benzBerake:
https://github.com/benzBerake/Grabby-FlashGot

Bundled source version: v0.60.1 plus the file-based JSON CLI adaptation.
Upstream license: GPL-3.0.
The SHA-256 of the bundled binary is recorded in the generated
chrome/content/DownloadItBinaryMetadata.sys.mjs file inside each XPI.

Aria2Next
=========

Aria2Next is based on aria2-next by AnInsomniacy:
https://github.com/AnInsomniacy/aria2-next

Bundled source version: v2.5.5.
Upstream license: GPL-2.0. The corresponding license text is included as
licenses/aria2-next-COPYING in the XPI. The pinned source tree and release
assets are available at:
https://github.com/AnInsomniacy/aria2-next/tree/v2.5.5
https://github.com/AnInsomniacy/aria2-next/releases/tag/v2.5.5
The SHA-256 of each bundled Aria2Next binary is recorded in the generated
chrome/content/DownloadItBinaryMetadata.sys.mjs file inside each XPI.

AriaNg
======

AriaNg is developed by MaysWind:
https://github.com/mayswind/AriaNg

Bundled source version: 1.3.14 standard asset bundle.
Upstream license: MIT. The corresponding license text is included as
licenses/ariang-LICENSE in the XPI. The pinned source tree and release asset
are available at:
https://github.com/mayswind/AriaNg/tree/1.3.14
https://github.com/mayswind/AriaNg/releases/tag/1.3.14
The packaging scripts verify the release archive and extracted standard asset
tree, including index.html, external scripts, styles, and Font Awesome fonts,
by fixed file size and SHA-256 before including them in the XPI. They add
Angular's ng-csp="no-unsafe-eval" marker to the local entry page so Angular
uses its CSP-compatible expression parser.
