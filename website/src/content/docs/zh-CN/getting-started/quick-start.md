## 检查工具栏面板

点击 DownloadIt 工具栏按钮。面板会显示当前服务状态、可用下载工具、“使用 DownloadIt 批量下载”入口和设置链接。

如果新安装的工具没有出现，使用**刷新下载工具**。已配置的内建集成会在后台探测，单个工具不可用不会阻止其他工具加载。

## 选择默认工具

在工具栏面板中选择可用工具，或打开 DownloadIt 设置，在**下载工具**中选择。Firefox 内建下载器始终可用，也不会通过包内 Windows helper 转交任务。

可以为 `magnet:` 和 `ed2k:` 链接分别设置默认工具。如果协议默认值为空或无效，Firefox 会保留原生外部协议流程。

## 发送单个链接

右键点击支持的链接并打开 DownloadIt 子菜单：

- 直接选择下载工具只发送本次任务，不修改默认值。
- **设为默认并下载**会先持久化所选工具，再发送链接。
- 普通 DownloadIt 操作使用当前默认工具。

DownloadIt 可以传递 URL、建议文件名、Referer、User-Agent 和允许发送的 Cookie 数据；实际能力取决于所选集成。

## 收集页面链接

从工具栏面板或右键菜单打开**使用 DownloadIt 批量下载**。筛选显式页面链接、选择需要的行，然后下载或复制。筛选和复制行为详见[下载入口与批量链接](../../guides/entry-points-and-links/)。

## 调整自动接管

自动接管默认保持保守。只有在希望 Firefox 已记住的某类下载交给 DownloadIt 时，才将相应扩展名加入白名单。黑名单和内建安全规则始终优先。

扩大规则前请先阅读[自动接管](../../guides/auto-capture/)。
