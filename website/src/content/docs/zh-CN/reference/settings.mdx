从 DownloadIt 工具栏面板进入设置。修改需要点击**应用**保存；内层编辑器可能先把修改保存到设置草稿。Firefox 策略锁定的控件无法修改。

## 下载管理器

选择普通链接、magnet 和 ed2k 的默认工具，设置任务启动行为，添加或编辑集成。状态和能力标签描述 DownloadIt 的传递路径。连接测试可以使用编辑器里尚未保存的值，不改变已保存 provider 的状态。

详见[下载工具集成](../../guides/download-managers/)与[自定义下载器](../../guides/custom-downloaders/)。

## 自动接管

白名单和黑名单决定 Firefox 已记住操作的文件类型是否转交。黑名单与内建安全规则优先，详见[自动接管](../../guides/auto-capture/)。

## 下载弹窗

| 控件 | 用途 |
| --- | --- |
| 无延时启用弹窗按钮 | 取消受支持确认按钮的等待时间。 |
| 检测 URL 文件名编码 | 尝试解释 URL 中编码的文件名。 |
| 其他文件名编码 | 添加 Firefox 支持的编码，或使用语言预设。 |
| 允许编辑文件名 | 保存前修改建议名称。 |
| 显示并复制完整链接 | 显示来源 URL 和复制控件。 |
| 另存为 / 保存到 / 保存并打开 | 显示相应保存操作。 |
| 保存到的位置 | 管理内置、自定义文件夹及显示名称。 |
| 自动列出尚未覆盖的盘符 | 把未覆盖的 Windows 盘符根目录加入保存到菜单。 |

详见[下载弹窗与保存](../../guides/download-dialog/)。

## 下载历史

清理按钮默认开启，完成提示音默认关闭。可选择内置声音或本地文件、调整音量并试听，详见[下载历史与提示音](../../guides/download-history/)。

<span id="link-groups"></span>

## 链接分组

管理批量链接选择器使用的内置和自定义分组、后缀、启用状态与显示名称。这些配置只影响链接分类，不修改浏览器全局文件处理方式，详见[下载入口与批量链接](../../guides/entry-points-and-links/)。

## 请求与隐私

**请求信息传递**统一展示 Cookie 全局开关，以及 Referer、User-Agent 的**自动附带**只读状态。此处还包括 IDM 本地协议兼容和卸载时保留配置，详见[请求与隐私](../privacy/)。

镜像设置属于开发者模式中显示的实验区域，详见[镜像加速](../../guides/mirrors/)。当前没有特定站点请求规则编辑器。

## 专用下载器

选择 yt-dlp，管理浮动菜单参数、启用状态和顺序。点击**应用**后更新已打开页面，详见[yt-dlp 视频菜单](../../guides/yt-dlp/)。

## 关于 / 诊断

查看扩展版本、后台服务、平台支持和 FlashGot 组件状态。DownloadIt 与独立构建的 helper 使用各自的版本。
