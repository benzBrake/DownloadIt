## 保存前选择操作

Firefox 显示受支持的下载确认弹窗时，DownloadIt 会加入文件名编辑、完整来源链接及复制控件，以及额外的保存操作。在 DownloadIt 设置的**下载弹窗**中选择需要显示的控件，然后点击**应用**。

- **保存到**：直接选择已配置的位置，不必每次浏览文件夹。
- **另存为**：打开文件选择器，指定名称和位置。
- **保存并打开**：Firefox 完成下载后打开文件。

可用的外部下载工具也会出现在弹窗中。Firefox 内建下载器不会重复显示，因为**保存文件**已经提供同一条路径。Firefox 已记住操作的文件类型可能跳过弹窗，详见[自动接管](../auto-capture/)。

## 配置保存到的位置

在**下载弹窗 → 保存到的位置**中，统一管理桌面、文档、图片、下载等内置位置和自定义文件夹。点击**添加文件夹**旁的箭头可添加内置位置。内置路径跟随系统设置；显示名称留空时使用本地化默认名称。

Windows 上可开启**自动列出尚未覆盖的盘符**，把尚未被已配置位置覆盖的盘符根目录加入菜单。这是可选功能，不会在 Linux 添加盘符条目。配置后点击**应用**。

## 修正文件名编码

开启**检测 URL 文件名编码**后，DownloadIt 会尝试解释下载 URL 中编码的文件名。传统编码可能有歧义，自动检测并不保证正确；下载文件的内容不决定 URL 文件名编码。

如果名称仍然乱码，在下载弹窗中打开编码控件，选择候选编码或 Firefox 原始文件名，也可以直接编辑名称。在设置的**其他文件名编码**中，可以输入 Firefox 支持的编码名称，或使用语言预设快速添加。完成编码编辑后，在设置页点击**应用**。
