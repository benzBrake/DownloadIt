## 清理下载记录

打开 Firefox **我的足迹 → 下载**。DownloadIt 会在 Firefox 清理控件旁加入**删除失败记录**和**删除失效记录**。显示这些按钮的设置默认开启。

- 删除失败记录：清理报告下载错误的记录。
- 删除失效记录：先检查成功下载的文件，只有文件已移动或删除时才清理记录。

两项操作只删除历史记录，不删除实际文件，也不取消下载。在**下载历史**设置中关闭清理按钮并点击**应用**后，已打开的我的足迹窗口也会移除按钮。

## 下载完成提示音

提示音默认关闭。在**下载历史**中开启**下载完成时播放提示音**，调整音量并使用**试听**检查。文件输入框留空使用内置提示音，也可以选择 Firefox 能播放的本地音频文件。**使用内置提示音**可恢复随包声音。点击**应用**保存。

内置提示音支持 Windows 和 Linux。Firefox `chrome` 目录中的音频可使用可移植的相对路径，目录外使用绝对路径，文件需要保持可访问。

<Screenshot id="download-history-settings" />

提示音适用于 Firefox 管理的下载，包括隐私窗口，不监听外部下载器或 yt-dlp。扩展启动时已有的完成记录不会响铃；多个下载重叠完成时会合并播放，避免叠加声音。
