## 右键菜单

DownloadIt 会为链接和包含链接的选区添加操作。直接选择某个下载工具只对当前提交生效；独立的**设为默认并下载**子菜单会先持久化所选工具。Firefox 策略可以禁止修改默认值，而不影响单次下载。

标准目标支持 HTTP、HTTPS、FTP、`magnet:` 和 `ed2k:`。可选下载器会根据各 provider 声明的协议能力进行过滤。

## Firefox 下载提示

对于支持的下载，DownloadIt 会与 Firefox 原生操作一起出现。Firefox 内建下载器不会在此处重复显示，因为**保存文件**已经提供同一条路径。

Firefox 记住某个文件类型的操作后，DownloadIt 还可以根据自动接管规则处理后续下载。受保护的扩展安装包和不支持的协议仍留在 Firefox。

## DownloadIt Links

链接窗口会从当前文档、子 frame 和开放的 Shadow DOM 收集显式 `a[href]` 与 `area[href]` 目标，不会嗅探网络流量或收集媒体元素资源。

筛选条件按以下方式组合：

- 多个类型选择之间按“或”匹配。
- 多个后缀选择之间按“或”匹配。
- 类型、后缀、协议和文本搜索之间按“且”组合。
- **全部**、**磁力**和 **ed2k** 协议模式互斥。

分类依据建议下载文件名或 URL 后缀判断。禁用和未命中的后缀组会归入**其他**。

## 只复制，不下载

选中行可以复制为：

- 每行一个 URL；
- 以制表符分隔的标题和 URL；
- Markdown 链接。

复制不会联系下载工具。批量下载会在进入 provider 前保持 URL、标题、文件名和逐链接元数据的行对齐。

链接分组名称和后缀可以在[设置参考](../../reference/settings/#链接分组)中编辑。
